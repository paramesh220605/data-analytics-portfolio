# Customer Churn and LTV Analytics Project

## Project Overview
This project analyzes customer churn and Customer Lifetime Value (LTV) to understand customer behavior and business performance.

## Tools Used
- SQL
- Power BI
- Excel
- CSV Dataset

## Objectives
- Identify customer churn patterns
- Analyze customer retention
- Calculate Customer Lifetime Value (LTV)
- Generate insights to support business decisions

## Project Files
- Dataset (CSV)
- SQL Queries
- Power BI Dashboard

## Conclusion
This project demonstrates how data analytics can help businesses understand customer behavior, improve customer retention, and make data-driven decisions.
