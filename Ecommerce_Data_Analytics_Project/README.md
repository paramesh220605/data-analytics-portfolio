# E-Commerce Revenue, Customer & Product Performance Analytics

## Project Overview
This beginner-friendly portfolio project provides an end-to-end analytics workflow for an e-commerce platform. It covers transactional revenue metrics, customer RFM segmentation, product category profitability, return rates, and logistics fulfillment comparisons.

## Project Structure
```
ecommerce_analytics_project/
│
├── data/
│   └── ecommerce_orders.csv      # Sample transactional dataset
│
├── sql/
│   └── analysis_queries.sql      # SQL analytical queries (PostgreSQL / MySQL)
│
├── python/
│   └── data_analysis.py          # Python EDA and KPI aggregation script
│
├── reports/
│   └── Analytics_Report.pdf      # Professional PDF report for stakeholders
│
└── README.md                     # Project documentation
```

## Tools & Technical Keywords Covered
* **Metrics:** Gross Merchandise Value (GMV), Net Revenue, Average Order Value (AOV), Return Rate %, Discount Dilution.
* **Customer Analytics:** RFM Segmentation (Recency, Frequency, Monetary Value), Customer Retention.
* **Operations:** 3PL Logistics vs. Direct Fulfillment, Product Velocity.
* **Tools:** SQL (CTEs, Window Functions), Python (Pandas, Data Aggregation), HTML/WeasyPrint (Executive Reporting).
